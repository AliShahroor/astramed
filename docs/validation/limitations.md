# Limitations

- Unvalidated demonstration prototype. Not a medical device. It does not diagnose, prescribe, or replace a flight surgeon.
- All astronaut data and baselines are synthetic. Prototype thresholds are illustrative.
- Only the CO₂ one-hour limit and the 600 mSv career limit are NASA-derived; neither revision text of NASA-STD-3001 was read directly (values taken from NASA technical briefs).
- No NASA-verified bone/muscle trajectory exists in the sources reviewed, so none is drawn.
- Browser reaction-time task is not the NASA PVT and is not clinically validated; timing depends on device and browser.
- Crew access control is simulated in the browser; there is no authentication or real notification.
- Offline support is implemented (service worker) but was not verified in a browser during development. Speech synthesis may rely on remote voices in some browsers.
- No NASA OSDR dataset is used.
