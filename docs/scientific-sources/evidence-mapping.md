# NASA evidence mapping

Every row corresponds to a record in `src/data/evidence.ts`. “Verified” means the value or wording was read from the NASA page named in the row during the verification pass; it does **not** mean the standard PDF itself was read, unless stated.

Categories (never mixed): **NASA-derived evidence** · **NASA experimental data** (none used) · **Synthetic astronaut data** · **Code Blue prototype rules**.

| Cabin CO₂ finding (NASA-derived rule) | [OCHMO-TB-004 Carbon Dioxide](https://www.nasa.gov/ochmo-tb-004-carbon-dioxide-2/) (cites NASA-STD-3001 Vol 2) | V2 6004 | One-hour average CO₂ partial pressure in the habitable volume is limited to 3 mmHg; 0.5% ≈ 3.8 mmHg. | Latest one-hour-average reading compared with 3 mmHg; strictly greater → Alert; exceedance = value − 3.
